# AudioEnhance
I aim to improve the sound quality of Geometry Dash with this mod.

Currently, i've added 2 features:
- Changing interpolation type to Spline, results in about +2 dB from 8khz to 16khz
- Adding an external MP3 loader (HUGE thanks to David Reid/mackron for [dr_mp3](https://github.com/mackron/dr_libs]!) to get around FMod's terrible mp3 loader.
